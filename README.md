# 🏥 MCP - Medical Cabinet Management System

A full-stack web application designed to help dental/medical cabinets manage patients, appointments, treatments, and administrative tasks efficiently.

---

## 🚀 Features

- 👨‍⚕️ Patient management (add, update, delete records)
- 📅 Appointment scheduling system
- 💊 Treatment history tracking
- 🔐 Authentication system (Admin / Doctor / patient)
- 📊 Dashboard with statistics
- 🌐 Responsive UI (works on all devices)

---

## 🛠️ Tech Stack

### Frontend
- React.js (Vite)
- TailwindCSS / CSS
- Axios

### Backend
- Node.js / Express.js *(or Laravel if you use it)*
- REST API
- JWT Authentication

### Database
- json
### AI tools

- used Groq api
